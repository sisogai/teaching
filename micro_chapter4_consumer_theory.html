4.1 Consumption Bundles and Budget Constraints

With $L$ goods, a consumer's spending pattern is described by a consumption bundle $x = (x_1, x_2, \ldots, x_L)$. Given prices $p = (p_1, p_2, \ldots, p_L)$ and income $w > 0$, the set of bundles the consumer can afford is determined by the following condition.

Definition 4.1.1 — Budget Constraint

A consumption bundle $x$ is feasible (affordable) if it satisfies the budget constraint:

$$p_1 x_1 + p_2 x_2 + \cdots + p_L x_L \leq w \quad \Longleftrightarrow \quad p \cdot x \leq w$$

The set of all feasible bundles is the budget set; its upper-right boundary is the budget line.

In the two-good case the budget line can be written as:

$$p_1 x_1 + p_2 x_2 = w \quad \Longleftrightarrow \quad x_2 = -\frac{p_1}{p_2}\,x_1 + \frac{w}{p_2}$$

4.3 Preferences and Utility Functions
Definition 4.3.1 — Utility Function

A utility function $u(x)$ assigns a number to each consumption bundle so as to represent the preference ordering. That is,

$$x \succ y \iff u(x) > u(y)$$

Common examples of utility functions:

$$u(x_1, x_2) = x_1^\alpha\, x_2^{1-\alpha}, \quad \alpha \in (0,1)$$

Indifference curves are convex toward the origin. Larger $\alpha$ reflects a stronger preference for good 1.

$$u(x_1, x_2) = ax_1 + bx_2, \quad a, b > 0$$

Indifference curves are straight lines (perfect substitutes). The MRS is constant.

$$u(x_1, x_2) = \min\{ax_1,\, bx_2\}, \quad a, b > 0$$

Indifference curves are L-shaped (perfect complements). The optimal bundle always satisfies $ax_1 = bx_2$.

4.4 Utility-Maximization Problem — Cobb–Douglas Case

Given the utility function $u(x_1,x_2) = x_1^\alpha x_2^{1-\alpha}$ and budget constraint $p_1 x_1 + p_2 x_2 = w$, the consumer solves:

$$\max_{x_1,x_2}\; x_1^\alpha x_2^{1-\alpha} \quad \text{s.t.}\quad p_1 x_1 + p_2 x_2 \leq w$$

Applying the Lagrangian method, the optimality condition is MRS = price ratio:

$$\frac{u_1}{u_2} = \frac{p_1}{p_2} \quad \Longrightarrow \quad \frac{\alpha}{1-\alpha}\,\frac{x_2}{x_1} = \frac{p_1}{p_2}$$
Walrasian Demand Functions (Cobb–Douglas)
$$x_1^* = \frac{\alpha\, w}{p_1}, \qquad x_2^* = \frac{(1-\alpha)\, w}{p_2}$$

The consumer spends fraction $\alpha$ of income on good 1 and $(1-\alpha)$ on good 2 — the constant expenditure-share rule.

Show derivation

From the first-order conditions:

$$\frac{\partial u}{\partial x_1} = \lambda p_1 \;\Rightarrow\; \alpha x_1^{\alpha-1}x_2^{1-\alpha} = \lambda p_1$$ $$\frac{\partial u}{\partial x_2} = \lambda p_2 \;\Rightarrow\; (1-\alpha)x_1^{\alpha}x_2^{-\alpha} = \lambda p_2$$

Dividing the two equations gives:

$$\frac{\alpha}{1-\alpha}\frac{x_2}{x_1} = \frac{p_1}{p_2} \;\Rightarrow\; x_2 = \frac{1-\alpha}{\alpha}\frac{p_1}{p_2}x_1$$

Substituting into the budget constraint $p_1 x_1 + p_2 x_2 = w$:

$$p_1 x_1 + \frac{1-\alpha}{\alpha}p_1 x_1 = w \;\Rightarrow\; \frac{p_1 x_1}{\alpha} = w \;\Rightarrow\; x_1^* = \frac{\alpha w}{p_1}$$

4.5 Comparative Statics of Demand: Elasticities

To measure changes in demand independently of units, we use elasticities.

Definition 4.5.3 — Elasticities of Demand
$$\varepsilon_w = \frac{\partial x_i}{\partial w}\cdot\frac{w}{x_i} \quad\text{(income elasticity)}$$ $$\varepsilon_{ii} = -\frac{\partial x_i}{\partial p_i}\cdot\frac{p_i}{x_i} \quad\text{(own-price elasticity)}$$ $$\varepsilon_{ij} = \frac{\partial x_i}{\partial p_j}\cdot\frac{p_j}{x_i} \quad\text{(cross-price elasticity, } j\neq i\text{)}$$

Cobb–Douglas results: Since $x_1^* = \alpha w / p_1$, we have $\log x_1 = \log\alpha + \log w - \log p_1$, giving:

$$\varepsilon_w = 1, \quad \varepsilon_{11} = 1, \quad \varepsilon_{12} = 0$$
